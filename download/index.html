Get Talkies.

Builds are published on GitHub Releases. The current latest channel is a prerelease. On first launch you choose and download a speech model; after that, dictation runs offline.

  • macOS

    Swift and SwiftUI · WhisperKit

    Available
    • macOS 15 or later
    • Apple Silicon recommended
    • Microphone permission
    Download for macOS (opens GitHub in a new tab)Setup guide for macOS (opens GitHub in a new tab)

  • Windows

    .NET WPF · Whisper.net

    Available
    • Windows 10 or 11, 64-bit
    • Installer or portable ZIP
    • Optional CUDA or Vulkan runtime
    Download for Windows (opens GitHub in a new tab)Setup guide for Windows (opens GitHub in a new tab)

  • Linux

    Zig · whisper.cpp · X11 and Wayland

    Available · maturing
    • x86_64 with AVX2
    • glibc 2.35 and GTK 4.6 or newer
    • GNOME, KDE, Hyprland, Sway, X11
    Download for Linux (opens GitHub in a new tab)Setup guide for Linux (opens GitHub in a new tab)

  • Android

    Kotlin and Compose · whisper.cpp

    Early access · signed APK
    • Android 9 (API 28) or newer
    • Includes Fire OS 7 and 8 tablets
    • Voice-typing keyboard

    Install from your phone

    Scan with your phone camera to open the Android APK download.

    Download Android APK (opens GitHub in a new tab)Setup guide for Android (opens GitHub in a new tab)

Verify what you download

Every release includes a SHA256SUMS file. Windows packages are currently unsigned, so compare checksums before installing. Models are checked against pinned SHA-256 hashes inside the app.
