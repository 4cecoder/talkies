# Archived planning material

This folder holds historical business planning that is not part of Talkies' current product or operating model. Talkies is an open-source MIT project; the active product direction is documented in [Product vision](../product/vision.md), and technical design belongs in [Architecture](../architecture/).

The old business architecture chart and its Mermaid source are retained for repository history only. Their revenue projections, paid tiers, account backend, and launch blockers are obsolete and must not be treated as current plans. Earlier pricing research remains under [`archive/docs`](../../archive/docs/PRICING_STRATEGY.md).

The former website's account, referral, rewards, and Convex backend implementation is retained under [`archive/frontend`](../../archive/frontend) for historical reference. It is not deployed or part of the current product. The Stripe environment provisioning script was removed because it contained credentials.

Superseded website authentication, support-form, and UX implementation plans are preserved in [`archive/frontend`](../../archive/frontend/). The active static website lives on the separate [`website` branch](https://github.com/4cecoder/talkies/tree/website); deployment and contribution notes are in [the website guide](../platforms/website.md).

The deprecated Flutter prototype is preserved in [`archive/flutter-prototype`](../../archive/flutter-prototype/README.md). The active Android implementation is Kotlin under [`mobile/android`](../../mobile/android/).

Historical Windows crash transmission and analytics implementation notes/tests are retained under `archive/windows`. Current diagnostics are local-only.
