## Usage Scenarios

### Scenario 1: First Time Setup

1. Read [QUICKSTART.md](QUICKSTART.md)
2. Install prerequisites: `brew install create-dmg`
3. Run test build: `SKIP_SIGNING=1 ./build-dmg.sh`
4. If successful, set up Apple Developer certificates (see QUICKSTART.md)

### Scenario 2: Development Build

```bash
cd /home/fource/talkies/packaging/macos
SKIP_SIGNING=1 ./build-dmg.sh
# Output: Talkies-1.0.0.dmg (unsigned, for testing)
```

### Scenario 3: Production Release

```bash
cd /home/fource/talkies/packaging/macos

# 1. Check release checklist
# See RELEASE_CHECKLIST.md

# 2. Build signed DMG
./build-dmg.sh

# 3. Notarize for public distribution
NOTARIZE=1 ./build-dmg.sh

# 4. Distribute
# Upload to GitHub Releases or website
```

### Scenario 4: Troubleshooting Build Issues

1. Check [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for your error
2. Run verbose build: `./build-dmg.sh 2>&1 | tee build.log`
3. Search documentation for error message
4. Check Apple Developer Forums

### Scenario 5: Custom DMG Background

1. Read [DMG_BACKGROUND_SPEC.md](DMG_BACKGROUND_SPEC.md)
2. Create 1600x800px PNG: `dmg-background.png`
3. Place in this directory
4. Build: `./build-dmg.sh` (will auto-detect)

## Common Commands Reference

```bash
# Test build (no signing)
SKIP_SIGNING=1 ./build-dmg.sh

# Production build (signed)
./build-dmg.sh

# Build with notarization
NOTARIZE=1 ./build-dmg.sh

# Custom version
VERSION=2.0.0 ./build-dmg.sh

# Combined options
VERSION=1.5.0 NOTARIZE=1 ./build-dmg.sh

# Check signing identities
security find-identity -v -p codesigning

# Verify built app
codesign --verify --deep --strict build/Talkies.app

# Check notarization status
xcrun notarytool history --keychain-profile talkies-notary-profile
```
