# Deprecated Flutter prototype

This directory contains Talkies' former Flutter and Dart prototype. It is preserved for historical
reference only. It is not a supported app, does not represent current product behavior, and is not
built, tested, or released by the project.

**Use the native Kotlin application in [`mobile/android/`](../../mobile/android/) for Android.**
The Flutter prototype has no active iOS release target. New features, fixes, and documentation
belong in the native platform implementations.

The files here may depend on obsolete packages and instructions. They are not covered by the
repository's current build, security, or support guarantees.
