# Talkies app icon

`talkies-app-icon.png` is the master artwork for the supported desktop apps. The platform assets are generated from that source:

- `talkies-app-icon.icns` is bundled by the macOS app packaging script.
- `talkies-app-icon.ico` is used for the Windows executable, window, and tray.
- `linux/assets/icon-*.png` is embedded by the Linux build.

The mobile Flutter app is deprecated; its old shell is not part of the supported desktop release targets.
