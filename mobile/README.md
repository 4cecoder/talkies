# Android

The supported Android application lives in [`android/`](android/) and is written in Kotlin. The
Flutter prototype has been deprecated and moved to [`archive/flutter-prototype/`](../archive/flutter-prototype/README.md).
Do not use Flutter commands or files to build the Android app.

Read the [Android platform guide](../docs/platforms/mobile.md) for model setup, supported Android
versions, offline behavior, and the current test commands.

Use the [Android build and user guide](../docs/platforms/mobile.md) for setup, model downloads, keyboard enablement, offline acceptance, and troubleshooting.
