Frequently Asked Questions

Which platform should I use?

macOS and Windows have the most complete, ready-to-use builds today — macOS needs Apple Silicon and macOS 15+, Windows needs 10/11 (64-bit). Linux has a working native build (X11 & Wayland) but is newer and less polished. There was a Flutter mobile app in mobile/, but it's deprecated and no longer built or maintained. See the platform picker above, or check docs/ROADMAP.md for the latest status.

Is this free?

Yes. Talkies is a free, open-source project with no subscriptions, no paywalls, and no in-app purchases. There's no account required to use the desktop apps.

Does my data leave my device?

No. Transcription runs locally using WhisperKit (macOS), Whisper.net (Windows), or whisper.cpp (Linux) — your audio and transcripts are never uploaded to a server. The in-browser demo on this site works the same way: it runs a small model client-side in your browser.

Can I use it offline?

Yes, once a build is installed and its model is downloaded, the desktop apps work completely offline. No internet connection is required for transcription.

How do I build it from source?

Each platform has its own build commands — see the AGENTS.md reference and each platform's own README (mac/, windows/, linux/, frontend/) for the exact steps.

Where do I report bugs or contribute?

Open an issue or pull request on GitHub. See CONTRIBUTING.md at the repo root for how to get started, and docs/ROADMAP.md for open work items.

What's the license?
